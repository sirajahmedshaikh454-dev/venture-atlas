# Venture Atlas

An interactive study site for Technology Entrepreneurship, Lectures 7–9: International Entrepreneurship, Legal Issues for Entrepreneurs, and The Marketing Plan.

Includes lecture pages with diagrams, a quiz arena (82 questions), flashcards (60), an interactive lab, real-world case studies, charts, and a revision center. Progress is saved in your browser.

## Run

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5173
```

An internet connection is needed for fonts, Three.js, GSAP, Lenis, Lucide and Chart.js (loaded from CDNs). Photos are from Unsplash.
